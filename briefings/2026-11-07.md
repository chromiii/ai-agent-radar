## 本周先看这 3 件事

下面是已在 Weekly Radar 中整理过、带原始来源的工程要点；不是让你自己再去解读一长串标题。

1. **Computer-use Agent 的递归改进**
   - **发生了什么**：本周一篇论文提出 CUA-Master，用嵌套双环递归改进扩展计算机使用代理的交互数据与能力。
   - **实际有什么用**：需要操作图形界面、缺少稳定 API 的桌面自动化任务。
   - **你可以怎么练**：用三张模拟界面截图和本地动作字典，手写一次观察→动作选择，并记录一个错误动作及回退方案（模拟，不接真实环境）。
   - **原始来源**：[点此阅读](https://arxiv.org/abs/2611.03126)
2. **编码代理的轨迹采集**
   - **发生了什么**：本周 SWE-Trail 指出独立多次采样轨迹会逐渐冗余，提出用历史引导的轨迹采集。
   - **实际有什么用**：为编码代理构建训练或评测轨迹时，控制采样冗余与覆盖。
   - **你可以怎么练**：用本地玩具仓库和三条模拟轨迹文本，标注每条轨迹的探索、编辑、验证步骤，并指出哪两条冗余（模拟数据，不运行真实代理）。
   - **原始来源**：[点此阅读](https://arxiv.org/abs/2611.02074)
3. **多模态协作编码评测**
   - **发生了什么**：本周 Co-Design Bench 基于真实用户编码会话构建 273 个任务，覆盖多模态编辑与仓库编辑两条轨道。
   - **实际有什么用**：评估编码代理在真实用户请求下的局部编辑与仓库级修改能力。
   - **你可以怎么练**：用一条模拟用户请求（含一张示意图描述）和一段玩具代码，写出期望修改点清单，并对照两条轨道判断属于哪类任务。
   - **原始来源**：[点此阅读](https://arxiv.org/abs/2610.35138)
