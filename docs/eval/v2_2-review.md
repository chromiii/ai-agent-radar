## 下一步应解决什么

优先改善逐项引用支持、对比结论的范围与练习完成标准。医疗对比仍把无直接基线的设计重点写得过满；RRF 的合法结果也可能与单路相同。这些是可复现的语义错误样本，适合下一阶段做来源支持核验和评测扩展。当前不据此引入 LangGraph、历史 RAG 或多 Agent 运行时。
