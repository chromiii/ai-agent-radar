# Ask Radar 学习卡

**你的问题**：我想用 MCP 给一个已有 Python 工具加接口，最近有哪些值得学的实现？

检索范围：2026-09-03 至 2026-10-02。

先读学习卡，再挑一个小练习；动手时间是建议预算。

### 1. 把已有 Python 工具封装为 MCP server 的近期实现

- **学习深度**：值得动手
- **30 秒概念**：MCP server 把本地 Python 函数按名称、描述和参数 schema 暴露为 agent 可调用的工具。
- **为什么值得了解**：2026 年 9-10 月检索到的多项工作把现有 Python 工具/库包成 MCP server 再叠加可复用技能层：一项工作用 OpenAI Agents SDK 与 Claude Code CLI 两条路径暴露 PSSE 工程函数供 agent 调用，另一项以 dependency-free Python 工具附带 MCP server，还有一个仓库给出 Python toolkit + MCP server + agent skills 的组合。
- **用在哪里**：给已有的 Python 分析/工程库加薄适配层，让 agent 复用现有函数而不是重写逻辑。
- **应用层学到这里**：工具 schema 与参数校验；工具描述文本影响选择；适配层与业务逻辑分离
- **动手建议（建议 20 分钟）**：用本地 schema 字典和 mock dispatcher 模拟一次工具调用分发。
- **完成标准**：打印出两次 mock 调用的工具名、参数与返回，且未知工具名返回明确错误。
- **证据类型**：近期研究方向
- **来源**：[S1](https://arxiv.org/abs/2609.40272)（发布 2026-09-30） / [S7](https://arxiv.org/abs/2609.36170)（发布 2026-09-28） / [S8](https://github.com/retentioneering/retentioneering-tools)（仓库活动 2026-09-30） / [S11](https://github.com/HKUDS/nanobot)（仓库活动 2026-10-02）

### 2. MCP 的授权与工具可见性

- **学习深度**：理解原因
- **30 秒概念**：工具级授权和可见性过滤决定哪个 agent 或用户能发现并调用哪些 MCP 工具。
- **为什么值得了解**：一份对六个官方 MCP SDK（Python、TypeScript、Go、Rust、C\#、Swift）的差距分析指出三类结构缺口：凭据绑定单一 Authorization header 难以服务人类与机器双身份、缺少预认证工具发现、缺少按工具的细粒度授权；该工作用 FastMCP 可组合扩展补齐跨 header 凭据归一、缓存 token 校验、免认证元数据端点和权限过滤的工具可见性。
- **用在哪里**：多个用户或服务账号共用一个 Python MCP server 时，避免越权看到或调用工具。
- **应用层学到这里**：凭据归一与身份区分；预认证工具发现；权限过滤的工具列表
- **动手建议（建议 20 分钟）**：用本地角色表模拟按角色过滤工具列表并拒绝越权调用。
- **完成标准**：对两个角色分别输出不同工具列表，且对未授权工具的调用返回拒绝。
- **证据类型**：实现 / 活动信号
- **来源**：[S2](https://arxiv.org/abs/2609.22573)（发布 2026-09-18）

### 3. 面向 agent 的工具接口成本取舍

- **学习深度**：先知道
- **30 秒概念**：工具返回内容的粒度与大小会影响 agent 的求解成功率与 token 成本。
- **为什么值得了解**：一份工作用进化式方法逐步生长出面向 Rocq 证明器的 MCP server，在成功率、每次求解成本和时间上优于只暴露编译器的基线与已有 MCP server，并可迁移到 Lean；另有仓库从压缩工具输出、沙箱化输出角度降低进入模型的 token。这提示接口返回粒度本身就是可优化的设计变量。
- **用在哪里**：设计工具返回格式时权衡信息完整性与 token 成本，减少 agent 的无效重试。
- **应用层学到这里**：返回结果裁剪与摘要；按求解成本评估接口；接口功能迭代取舍
- **动手建议（建议 15 分钟）**：对比同一 mock 输出完整版与摘要版的字符数与关键字段保留情况。
- **完成标准**：打印两种返回的字符长度，并确认摘要版仍保留预定义的关键字段。
- **证据类型**：实现 / 活动信号
- **来源**：[S5](https://arxiv.org/abs/2609.39544)（发布 2026-09-30） / [S9](https://github.com/mksglu/context-mode)（仓库活动 2026-10-02） / [S10](https://github.com/headroomlabs-ai/headroom)（仓库活动 2026-10-02）
