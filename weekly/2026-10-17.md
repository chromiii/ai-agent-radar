## 这周先学什么

### 1. Computer-use Agent 训练环境合成

- **学习深度**：理解原因
- **30 秒概念**：让代理在合成 GUI 软件环境中练习操作，以扩大覆盖并减少过拟合。
- **为什么值得了解**：SoftwareGym 提出自动合成 GUI 软件环境的流水线，用于规模化训练计算机使用代理。
- **用在哪里**：需要大量多样化桌面软件交互数据、但原生环境搭建成本高的代理训练场景。
- **应用层学到这里**：GUI 环境合成与任务生成；原生环境与浏览器环境的取舍；应用特定过拟合风险
- **动手建议（建议 20 分钟）**：用本地字典模拟三个“软件环境”配置（应用名、可用按钮、任务目标），写一个玩具调度器随机抽取环境并记录一次动作选择，说明为何需要多样化环境。
- **完成标准**：输出三份环境配置和一条动作记录，并写一句多样化环境对过拟合的作用。
- **来源**：[来源 1](https://arxiv.org/abs/2610.12611)

- **学习卡 ID**：`lc-d93f145be322`

### 2. 从人类 GUI 演示归纳可复用技能

- **学习深度**：理解原因
- **30 秒概念**：把人类操作演示转成可复用的代理技能，而非一次性任务脚本。
- **为什么值得了解**：Work2Skill 提出捕获人类 GUI 经验并归纳为可复用技能，用于陌生软件与工作流。
- **用在哪里**：需要把人工操作经验沉淀为代理可复用流程的桌面自动化场景。
- **应用层学到这里**：演示记录与动作上下文；工作流规则与任务细节分离；技能复用边界
- **动手建议（建议 20 分钟）**：用本地 JSON 模拟两条人类点击序列（应用、按钮、目标），手工抽出共同步骤作为“技能”，并标注一条只属于单次任务的细节。
- **完成标准**：产出两条模拟序列、一个共同技能步骤和一条被排除的任务细节。
- **来源**：[来源 1](https://arxiv.org/abs/2610.12984)

- **学习卡 ID**：`lc-c1b31c8c05bd`

### 3. 长程代理的残差记忆压缩

- **学习深度**：理解原因
- **30 秒概念**：在文本摘要之外补充有界软记忆，帮助冻结模型近似完整历史下的决策。
- **为什么值得了解**：REMORY 提出用神经记忆网络在摘要后追加有界软记忆 token，用于长程代理上下文压缩。
- **用在哪里**：上下文窗口有限、需要跨多步保持历史信息的长程代理。
- **应用层学到这里**：摘要压缩的决策信息损失；有界软记忆 token；冻结模型下的近似续写
- **动手建议（建议 20 分钟）**：用本地小文本模拟一段历史与一份摘要，手工列出摘要遗漏的两条关键事实，并写出若补充“记忆槽”应放什么。
- **完成标准**：提交一份模拟摘要、两条遗漏事实和两个记忆槽内容。
- **来源**：[来源 1](https://arxiv.org/abs/2610.11287)

- **学习卡 ID**：`lc-eb76b50b54c8`

### 4. 编码代理的测试质量评测

- **学习深度**：理解原因
- **30 秒概念**：评估编码代理生成的测试，不能只看是否匹配单一参考实现。
- **为什么值得了解**：TestPrism 指出用单一参考解评估测试会高估质量，并提出联合成功指标。
- **用在哪里**：使用编码代理生成单元测试、需要判断测试是否真正有区分度的工程场景。
- **应用层学到这里**：单一参考解的偏差；有效与无效实现对照；联合成功指标
- **动手建议（建议 20 分钟）**：用本地两个玩具函数（一个正确、一个错误）和一份模拟测试，手工判断该测试能否同时通过正确实现并拒绝错误实现，记录结论。
- **完成标准**：写出两个玩具函数、一份模拟测试和一句联合判断结论。
- **来源**：[来源 1](https://arxiv.org/abs/2610.12289)

- **学习卡 ID**：`lc-92ceedb2a713`

### 5. 无状态长程研究代理

- **学习深度**：理解原因
- **30 秒概念**：把研究状态外置、由调度决定下一步，以减少长程代理的重复与空转。
- **为什么值得了解**：Stateless Language Agents 将长程研究失败归因于状态存放位置与下一步决策者，并提出无状态设计。
- **用在哪里**：长时间自动研究或多步探索、需要控制重复工作和 token 消耗的代理系统。
- **应用层学到这里**：研究状态外置；下一步决策归属；重复工作与空转失败模式
- **动手建议（建议 20 分钟）**：用本地列表模拟三条研究子任务与一份外部状态文件，手工安排一次调度并标出哪条会被跳过以避免重复。
- **完成标准**：产出三条模拟子任务、一份状态记录和被跳过的一条及理由。
- **来源**：[来源 1](https://arxiv.org/abs/2610.07625)

- **学习卡 ID**：`lc-3f04751adc62`
