### 1. Computer-use Agent 的递归改进

- **学习深度**：理解原因
- **30 秒概念**：让模型在真实桌面环境里观察界面、选择动作并执行，再依据反馈迭代改进。
- **为什么值得了解**：本周一篇论文提出 CUA-Master，用嵌套双环递归改进扩展计算机使用代理的交互数据与能力。
- **用在哪里**：需要操作图形界面、缺少稳定 API 的桌面自动化任务。
- **应用层学到这里**：观察与动作空间设计；交互数据多样性与可控性；递归反馈与收益递减
- **动手建议（建议 20 分钟）**：用三张模拟界面截图和本地动作字典，手写一次观察→动作选择，并记录一个错误动作及回退方案（模拟，不接真实环境）。
- **完成标准**：保存三条观察与动作记录，并写明一个错误动作的回退处理。
- **来源**：[来源 1](https://arxiv.org/abs/2611.03126)

- **学习卡 ID**：`lc-33f8aff81891`

### 2. 编码代理的轨迹采集

- **学习深度**：值得动手
- **30 秒概念**：编码代理通过探索、编辑、验证的长序列解决仓库问题，这些轨迹可作为后训练数据。
- **为什么值得了解**：本周 SWE-Trail 指出独立多次采样轨迹会逐渐冗余，提出用历史引导的轨迹采集。
- **用在哪里**：为编码代理构建训练或评测轨迹时，控制采样冗余与覆盖。
- **应用层学到这里**：轨迹的探索-编辑-验证结构；独立采样的冗余问题；历史引导的采集策略
- **动手建议（建议 25 分钟）**：用本地玩具仓库和三条模拟轨迹文本，标注每条轨迹的探索、编辑、验证步骤，并指出哪两条冗余（模拟数据，不运行真实代理）。
- **完成标准**：完成三条轨迹的步骤标注，并写出一句冗余判断理由。
- **来源**：[来源 1](https://arxiv.org/abs/2611.02074)

- **学习卡 ID**：`lc-938f5dc32633`

### 3. 多模态协作编码评测

- **学习深度**：先知道
- **30 秒概念**：评测编码代理能否把真实用户的多模态请求转化为可用的应用修改。
- **为什么值得了解**：本周 Co-Design Bench 基于真实用户编码会话构建 273 个任务，覆盖多模态编辑与仓库编辑两条轨道。
- **用在哪里**：评估编码代理在真实用户请求下的局部编辑与仓库级修改能力。
- **应用层学到这里**：多模态编辑与仓库编辑两条轨道；从真实会话构建任务；无参考评测思路
- **动手建议（建议 15 分钟）**：用一条模拟用户请求（含一张示意图描述）和一段玩具代码，写出期望修改点清单，并对照两条轨道判断属于哪类任务。
- **完成标准**：产出修改点清单，并标注任务所属轨道及理由。
- **来源**：[来源 1](https://arxiv.org/abs/2610.35138)

- **学习卡 ID**：`lc-11c338bac904`

### 4. 长程编码的相互依赖规格

- **学习深度**：理解原因
- **30 秒概念**：长程软件开发中编码代理需同时满足接口兼容、错误处理等多维规格且不破坏依赖。
- **为什么值得了解**：本周一篇论文指出当前任务规格在数量与多样性上不足，提出相互依赖规格来扩展长程编码。
- **用在哪里**：设计编码代理任务或验收标准时，显式加入相互约束的规格。
- **应用层学到这里**：多维规格的相互依赖；主目标与约束的平衡；避免任务退化为琐碎
- **动手建议（建议 20 分钟）**：为一个玩具函数写三条相互约束的规格（接口、错误处理、依赖），并说明若只保留主目标会漏掉什么。
- **完成标准**：写出三条相互约束规格及一句遗漏风险说明。
- **来源**：[来源 1](https://arxiv.org/abs/2610.40256)

- **学习卡 ID**：`lc-8741373104a1`

### 5. 可复现网页代理环境

- **学习深度**：先知道
- **30 秒概念**：为网页代理提供多样、可执行、可重置的网站环境，用于可复现训练与评测。
- **为什么值得了解**：本周 WebAnything 提出从真实 URL 自动重建源依据、可复用的网页环境。
- **用在哪里**：需要可重置网页环境来复现网页代理行为时。
- **应用层学到这里**：可重置环境的意义；捕获回放的覆盖限制；源依据重建思路
- **动手建议（建议 20 分钟）**：用两个本地静态 HTML 玩具页面模拟一次点击流程，记录状态并手动重置，说明捕获回放可能漏掉哪种交互。
- **完成标准**：保存一次点击流程记录与重置结果，并写出一句覆盖缺口。
- **来源**：[来源 1](https://arxiv.org/abs/2610.37786)

- **学习卡 ID**：`lc-0b73660e3192`
